FoodMapper 0.1.6

Manual Override, model setup, and data handling fixes.

Fixes

  • Manual Override searches every target row saved with a new session
  • Manual selections retain target IDs and row fields in exports without an inferred score
  • Existing verified GTE-Large installations remain valid after model-card metadata changes
  • CSV and TSV imports handle quoted fields and reject inconsistent row widths
  • Interrupted database and cache writes no longer replace valid stored data with partial files

Changes

  • GTE-Large uses checked parallel downloads when the model host supports range requests
  • Download progress, cancellation, retries, speed, and time estimates reset for each attempt
  • Existing Anthropic API keys move into the macOS Keychain after a successful Keychain write
  • Advanced Help stays hidden until advanced options are enabled
  • Publication links and research figures match the published paper
